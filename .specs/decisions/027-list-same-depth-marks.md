# ADR-027 — 縦線を廃止し、同じ深さの項目の marker を濃くする

Status: **Accepted**（2026-09-24）

Related: ADR-026, `ui/ui-spec.md` §7, `quality/acceptance-criteria.md` §C

## Context

縦に書き進める際、現在の項目と同じ深さにある項目の把握が求められる。同一深度を探す際、視線は marker を縦方向に追う。

一方、ADR-026 ではカーソルを含むリストにおいて子リストを持つ項目の marker 直下に縦線を引いていた。そのため、入れ子が深いリストでは字下げ部分に多数の線が並ぶ。さらに、縦線は marker から離れた位置に引かれるため、確認の際に横方向への視線移動が発生していた。

## Decision

ADR-026 §2 の縦線を廃止し、marker の濃淡で同じ深さを示す。

- カーソルのある項目と、同一の親を持つ兄弟項目の marker を太字にする。色は `--syntax-marker` のままとする。
- 同一の最外側リストにある他の marker は、`--syntax-marker` を背景色へ寄せた薄い色にする。
- 最上位階層にカーソルがある場合は、最上位の項目同士を兄弟とみなす。
- カーソルがリスト外にある場合や、別リストの marker に対しては何もしない。
- 項目の継続行や行頭にカーソルがある場合は、その行の項目を基準とする。

差異は色相ではなく、明るさと太さで表現する。薄い marker も同じオレンジ色のため、色を見分けにくい場合でも濃淡として認識できる。なお、本文の色と文字位置は変更しない。

## 採用しなかった案

- **兄弟の範囲に 1 本だけ縦線を引く**: 階層が深いほど線が marker から離れ、横方向の視線移動が必要となるため。
- **同じ深さの行の字下げ部分に淡い帯を敷く**: 色面が広くなり、アクセントカラーを大面積に使用しない方針に反するため。
- **同じ深さ以外の本文を薄くする**: 効果は高いものの、薄めた本文のコントラストが不足し、可読性が低下するため。

## Consequences

- 字下げの縦線は表示しない。ADR-026 の折り返しの頭揃えは維持する。
- カーソル移動に伴い、濃い marker もその深さへ移動する。文字位置は変わらない。
- 設定項目は追加しない。
