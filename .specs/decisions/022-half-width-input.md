# ADR-022 — 全角英数字・記号を IME 確定時に半角へ変換する

Status: **Accepted**（2026-09-18）

Related: AUTO-040（行頭の全角 Markdown 記号の置き換え）、`ui/ui-spec.md` §7 / §13、`quality/acceptance-criteria.md` §C、`AGENTS.md` §4 / §8

## Context

MS-IME での日本語入力時に英単語や数値を入力すると、`Ａ` `１２` `！` `（` などの全角文字で確定される。半角にするには IME を切り替えて再入力するか、確定前に変換キーで半角候補を選択する必要があり、日本語と英数字が混在する文書では頻繁に発生する（1 文書あたり数十回）。

AUTO-040 では行頭の `＃` `ー` `＞` などを半角へ置換する処理を導入したが、対象は文脈上全角にする意味がない行頭の Markdown 記号に限定されており、本文中の英数字や記号は対象外となっている。

一方で、全角を維持すべき文字も存在する。`。` `、` `「」` `・` `ー` など ASCII に対応のない和文文字に加え、`：` `；` `，` `．` `～` は和文の句読点や区切り記号として全角のまま使用される場合がある。これらを一律に半角化すると、利用者の意図した文章を損なう問題がある。

## Decision

### 1. IME 確定範囲の全角英数字・記号を半角へ変換する

対象は U+FF01〜U+FF5E の全角英数字・記号（`Ａ〜Ｚ` `ａ〜ｚ` `０〜９` `！？（）＋－＠＃` など）、全角空白（U+3000）、および MS-IME が `"` `'` の代わりに出力する `“ ” ‘ ’` とする。対応マッピングは 1 つの変換テーブルとして `domain/document/half-width` に配置する。

変換対象は**該当 composition で確定した範囲のみ**とする。カーソル以前の全角文字は意図して残された可能性があるため変更しない。行頭の Markdown 記号（AUTO-040）の判定を優先し、そちらで置換された場合は半角化を実行しない。

IME を介さない直接入力（`inputHandler` 経路）でも同じテーブルを用いて変換する。

### 2. 対象外文字の非変換

`。` `、` `「」『』` `・` `ー`（長音）、ASCII に対応のない和文括弧（`【】〈〉《》` など）、かな・カナ・漢字はテーブルに含めず、設定にかかわらず変換しない。

### 3. 区切り記号の分離とトグル化（既定: off）

`，` `．` `：` `；` `～`（および波ダッシュ `〜`）はテーブル内で「区切り段」として分離し、独立したトグルで切り替える。和文の区切りとして全角を使用する文章を既定で変更しないため、既定値は off とする。

### 4. Settings へのトグル追加と反映方式

Settings の Editor 内に「入力の自動修正」の小見出しを設け、以下の 2 つのトグルを追加する。

- 「全角の英数字と記号を半角にする」（`halfWidthAscii`、既定 on）
- 「区切り記号も半角にする」（`halfWidthSeparators`、既定 off。前者が off のときは disabled）

`AGENTS.md` §4 に従い、常設 UI ではなく Settings に配置する。設定変更時は Compartment で差し替え、Editor の再生成は行わない。

## Consequences

- 既定設定では、日本語入力のまま `Ｑｕｉｅｔ １２：３０` と確定すると `Quiet 12：30` となる。区切り記号のトグルを on にすると `Quiet 12:30` となる。
- 全角英数字を意図して入力する場合は、設定を off にするか確定後に再入力する。個別の確定で例外扱いする手段は設けない。
- AUTO-040 による行頭記号の置換は、本設定が off であっても従来どおり動作する。
- 本処理はファイル保存時の一括変換ではなく入力時の置換であるため、既存ノートの全角文字は書き換わらない（`AGENTS.md` §8）。

## Alternatives

### 文字ごとの個別トグル

不採用。`！` `？` `（）` `：` など文字ごとに設定項目を並べると 6〜7 行に増加し、設定項目を安易に増やさない方針（`AGENTS.md` §4）に反する。用途が分かれるのは区切り記号のみであるため、1 つのトグルに集約した。

### 判断が分かれる文字を一律に対象外とする

不採用。`：` や `～` も半角化したい要求に対応できない。独立したトグルを 1 つ設けることで、双方の運用要件を満たせる。

### 保存時に一括で半角へ変換する

不採用。ファイル保存時の無条件な全体再整形は禁止されている（`AGENTS.md` §8）。また、過去に入力した既存の文字まで書き換えてしまうため。

### カーソル以前の行全体を走査して変換する

不採用。以前から入力されていた全角文字（意図的に残した文字や、設定 off の間に書かれた文字）まで書き換えてしまうため。対象範囲を composition に限定することで、直前に入力された文字のみを変換できる。
