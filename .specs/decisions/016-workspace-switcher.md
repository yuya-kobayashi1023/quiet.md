# ADR-016 — Workspace switcher

Status: **Accepted**（2026-09-09）

Supersedes: ADR-015

Related: U-001, U-005, U-009, U-011, ADR-013, `ui/ui-spec.md` §2 / §3, `architecture/interfaces.md` §8 / §11

## Context

ADR-015 で Sidebar 最下部に **WORKSPACE** セクションを置き、過去に開いた Workspace を
10 件すべて並べた。切り替えはできるようになったが、実際に使うと次が問題になった。

- 常に 10 行が居座り、Sidebar の縦を占める。Notes より下にあるのに、Notes より行数が多い日がある
- Workspace は「今どこにいるか」を決める最上位の軸なのに、Recent の下という末端に置かれている
- 履歴一覧は切り替えるときにしか要らない。常時見えている必要がない

## Decision

WORKSPACE を **Sidebar 最上部**へ移し、**現在の Workspace 1 行 + ドロップダウン**にする。

### 1. 位置は Notes の上

Workspace は Notes / Archive の内容そのものを決める。所属を決めるものを、決まった結果より
下に置かない。Recent は Workspace に紐づかないので、順序は Workspace → Notes → Archive → Recent。

### 2. 常設するのは現在の 1 行だけ

セクション見出し `WORKSPACE` の下に、今開いている Workspace を 1 行出す。Notes の選択行と
同じハイライトを付ける（ADR-015 §3 の「現在地が Sidebar だけで分かる」は維持する）。
Workspace 未選択のときは `Workspace を選択` と出し、ハイライトしない。

### 3. 履歴はドロップダウンへ

見出しの右に `⌄` を置く。押すと履歴が開いた新しい順に並ぶ。現在の行そのものを押しても開く。

- 各行は フォルダ名 + 相対時刻（`たった今` / `2時間前` / `昨日` / `1週間前`）。
  並び順が既に「新しい順」なので、絶対時刻は出さない
- 表示名はフォルダ名だけ。同名フォルダが並びうるので Tooltip は常にフルパス
- 今開いている Workspace も一覧に残し、アイコンを accent で塗って現在地を示す
- 一覧は最大 232px でスクロールする。10 件全部を一度に見せることは目的にしない

`.tree` は overflow を持つので、Popover は `.tree` の外・Sidebar 直下へ置く。
位置は開いた時点の anchor から確定させる（後から effect でずらすと 1 フレーム別の場所に見える）。

### 4. 「新しいワークスペースを開く…」はスクロールの外

一覧の下に、一覧のスクロールに巻き込まれない固定行として置く。押すと OS のフォルダ選択
ダイアログが開く（既存の `chooseWorkspace` / `openWorkspacePath`）。新規フォルダでも既存
フォルダでもよい。履歴が 0 件でもこの行は必ず出るので、ADR-015 §7 の「空でも `+` が要る」は
ここで満たされる。

ADR-015 で見出しに置いた `+` は廃止する。見出しの操作は `⌄` 1 つにする。

### 5. 畳んだ Rail からも切り替えられる

Rail の最上部に Workspace アイコンを置き、同じドロップダウンを開く。Rail の他のボタンとは
divider で分ける。Sidebar を畳んでいるときこそ、現在地の確認と切り替えの導線が要る。

### 6. アイコンは Folder と分ける

Workspace は「フォルダの中身の集合」であって、ツリー上の 1 フォルダではない。同じ絵にすると
Notes のフォルダ行と同じものに見える。重ねた面（Layers）で表す。

### 7. Keyboard

- `⌄` / 現在行 で開閉。開くと今の Workspace へ focus が乗る
- `↑` `↓` で候補を移動する。末尾の「新しいワークスペースを開く」も移動先に含める
- `Escape` と外側クリックで閉じる
- 切り替えが成功したら閉じる。Context menu の操作では閉じない（履歴から削除して続けられる）

### 8. ADR-015 から変えないもの

- 保持は 10 件。表示件数の設定は作らない
- 保存先は App settings の `workspaces`
- 開く経路は `openWorkspacePath(path)` 1 本
- 同一判定は `pathKey`
- 開けなければその場で履歴から外して Toast
- Context menu は 開く / 新しいウィンドウで開く / パスをコピー / エクスプローラーで表示 / 履歴から削除

## Consequences

- 履歴が何件あっても Sidebar の常設高さは 50px（見出し + 1 行）で固定になった
- 履歴は「開かないと見えない」ものになった。切り替え頻度が低い人ほど得をする
- Popover が Sidebar 幅（226px）より広い 268px ではみ出す。フォルダ名を読める幅を優先した
- Popover を `.tree` の外に置くため、位置計算が Sidebar に対する相対座標になった。
  一覧を開いたまま `.tree` をスクロールすると anchor と離れるが、Workspace 行は `.tree` の
  先頭にあり、閉じるまでの間に離れる幅は小さいので許容する

## Alternatives

### ADR-015 のまま一覧を出しっぱなしにする

却下の理由は Context のとおり。10 行が常に居座ることが問題だった。

### Top bar の Breadcrumb からドロップダウンで切り替える

ADR-015 と同じ理由で採らない。Breadcrumb は文書の所属を示す表示であり、Top bar の役割を増やさない。

### 一覧に「最後に開いた日時」を絶対時刻で出す

日時そのものを読みたい場面が思いつかない。並び順で「新しい順」は既に分かるので、
どのくらい前かの粗い手がかりで足りる。
