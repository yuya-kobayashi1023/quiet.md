# ADR-020 — ピン止めしたノートを Sidebar の先頭に置く

Status: **Accepted**（2026-09-17）

Amends: ADR-019（並び順。ピン止めした行を先頭へ寄せる）

Related: U-005, U-024, ADR-013, ADR-019, `ui/ui-spec.md` §2 / §13, `ui/interactions.md` §13, `architecture/interfaces.md` §5

## Context

ADR-019 により Notes は作成日時の新しい順に並ぶ。時系列で蓄積する運用には合うが、「いま手を付けている数本」は作成日時とは無関係に存在する。長期の TODO、進行中の下書き、頻繁に参照するメモなどである。これらは日が経つほど一覧の下へ沈み、サブフォルダにあればフォルダを開かなければ見えない。

Recent（ADR-013）は Workspace 外のファイルを開いた順に並べる領域であり、この用途には使えない。Search All（ADR-011）は名前を覚えていることが前提で、「いつも見る数本」を一覧の上に固定する手段にはならない。

## Decision

### 1. ピン止めした行は区分の先頭に depth 0 で置く

Notes と Archive の各区分で、ピン止めしたファイル行をフォルダ行より前に depth 0 で配置する。サブフォルダの中にあるファイルも同じ扱いとし、フォルダ側には重複して出さない。ピン止め同士は作成日時の新しい順とし、作成日時が同じファイルは名前順とする（ADR-019 と同じ tie-break）。

ピン止め以外の行は ADR-019 の並びを維持する。ピン止めはその上に載る層であり、既存の並び規則を変えない。

### 2. 状態は `.quiet/workspace.json` の `pinned` に持つ

Workspace metadata に相対パスの一覧 `pinned` を追加し、Archive の `archived` と同じ形で持つ。`pinned` キーを持たない既存の workspace.json は空の一覧として読む。Native は `setPinned(relativePath, pinned)` を提供し、`setArchived` と同じく更新後の metadata を返す。

### 3. 操作は Context Menu だけに置く

ファイル行の Context Menu に「ピン止め」「ピン止めを外す」を、アーカイブ項目の上に置く。常設 UI は足さない（`AGENTS.md` §4）。結果は Toast で返す。外す操作は右クリック一つで戻れるため、Toast に Undo は付けない。

### 4. ピン止めした行はピンのアイコンで示す

ピン止めした行はファイルのアイコンの代わりにピンのアイコンを出す。行が先頭にある理由を、見出しや区切り線を増やさずに示すためである。

### 5. Recent には効かない

Recent は Workspace 外のファイルを開いた順に並べる領域であり、Workspace metadata の相対パスに紐づくピン止めは適用できない（ADR-013 の Archive と同じ理由）。Recent の Context Menu にもピン止めは出さない。

### 6. Archive とは独立した flag

ピン止めしたノートをアーカイブしてもピンは残り、Archive 区分の先頭に出る。戻してもピンは残る。Archive と同じく相対パスで持つため、ファイル名を変更するとピンは外れる。Rename の追跡は足さない。

## Consequences

- ピン止めしたファイルは所属フォルダから見えなくなる。フォルダを開いてもそこには出ず、先頭のピン止めの群にだけ出る。
- ピン止めが増えると、フォルダ行が画面の下へ押し下げられる。ピン止めの件数に上限は設けず、増やしすぎない運用に委ねる。
- `buildTree` はピン止め一覧を引数に取る。`TreeRow` のファイル行は `pinned` を持ち、描画側は行の位置ではなく flag でアイコンを切り替える。
- Search All の結果と Command Palette の並びには影響しない。

## Alternatives

### フォルダごとにピン止めする（所属フォルダの先頭に置く）

不採用。閉じたフォルダの中にあるピン止めは見えず、ピン止めの目的を果たさないため。

### Front Matter に `pinned:` キーを持つ

不採用。ノート本文を書き換えることになり、走査時に全ファイルの先頭を読む必要があるため（ADR-019 の `created` を使わない理由と同じ）。

### 「Pinned」の区分見出しを足す

不採用。先頭の群とピンのアイコンで足り、常設 UI が増えるため（`AGENTS.md` §4）。
