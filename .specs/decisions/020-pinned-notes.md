# ADR-020 — ピン止めしたノートを Sidebar の先頭に置く

Status: **Accepted**（2026-09-17）

Amends: ADR-019（並び順。ピン止めした行を先頭へ寄せる）

Related: U-005, U-024, ADR-013, ADR-019, `ui/ui-spec.md` §2 / §13, `ui/interactions.md` §13, `architecture/interfaces.md` §5

## Context

ADR-019 による作成日時の新しい順の並びでは、作成日時によらず頻繁に参照するノート（長期の TODO、進行中の下書き、参照メモなど）へのアクセス性が低下する。時系列での蓄積には適しているものの、日数の経過に伴いこれらは一覧の下方へ移動し、サブフォルダ内にある場合はフォルダを開かなければ確認できない。

Recent（ADR-013）は Workspace 外のファイルを開いた順に並べる領域であり、本用途には使用できない。また、Search All（ADR-011）はファイル名の把握を前提とするため、特定のノートを一覧上部に固定する手段にはならない。

## Decision

### 1. ピン止めした行を各区分の先頭に depth 0 で配置する

Notes と Archive の各区分において、ピン止めしたファイル行をフォルダ行より前に depth 0 で配置する。サブフォルダ内のファイルも同様に扱い、所属フォルダ側には重複して表示しない。ただし、所属フォルダ内のファイルがすべてピン止めされている場合でもフォルダ行自体は残す。ピン止めしたファイル同士は作成日時の新しい順に並べ、作成日時が同一の場合は名前順とする（ADR-019 と同じ tie-break）。

ピン止めされていない行は ADR-019 の並び順を維持する。ピン止めは既存の並び規則を変更せず、その上位層として適用する。

### 2. 状態を `.quiet/workspace.json` の `pinned` に保持する

Workspace metadata に相対パスの一覧 `pinned` を追加し、Archive の `archived` と同一の形式で保持する。`pinned` キーを持たない既存の workspace.json は空の一覧として読み込む。Native は `setPinned(relativePath, pinned)` を提供し、`setArchived` と同様に更新後の metadata を返す。

### 3. 操作は Context Menu のみに配置する

常設 UI は追加せず（`AGENTS.md` §4）、ファイル行の Context Menu においてアーカイブ項目の上に「ピン止め」「ピン止めを外す」を配置する。実行結果は Toast で通知する。ピン止めを外す操作は右クリック操作のみで元に戻せるため、Toast に Undo は設けない。

### 4. ピン止めした行をピンのアイコンで表示する

ピン止めした行は、ファイルアイコンの代わりにピンのアイコンを表示する。見出しや区切り線を追加せずに、行が先頭に配置されている理由を示すためである。

### 5. Recent には適用しない

Recent にはピン止めを適用しない。Recent は Workspace 外のファイルを開いた順に並べる領域であり、Workspace metadata の相対パスに紐づくピン止めを適用できないためである（ADR-013 の Archive と同じ理由）。Recent の Context Menu にもピン止め項目は表示しない。

### 6. Archive とは独立した flag とする

ピン止めは Archive と独立した flag とする。ピン止めしたノートをアーカイブしてもピン止め状態は保持され、Archive 区分の先頭に表示される。アーカイブから元に戻した場合もピン止め状態は維持される。Workspace metadata が保持する相対パス（pinned・archived・lastOpened）は、Rename に追従して書き換える（2026-09-18 決定）。

## Consequences

- ピン止めしたファイルは所属フォルダ内には表示されず、先頭のピン止め一覧にのみ表示される（所属フォルダの行自体は残る）。
- ピン止め件数の増加に伴いフォルダ行が下へ押し下げられる。ピン止め件数に上限は設けず、過度に増やさない運用に委ねる。
- `buildTree` はピン止め一覧を引数に取る。`TreeRow` のファイル行は `pinned` を保持し、描画側は行の位置ではなく flag でアイコンを切り替える。
- Search All の検索結果および Command Palette の並び順には影響しない。

## Alternatives

### フォルダごとにピン止めする（所属フォルダの先頭に置く）

不採用。フォルダを閉じているとピン止めしたファイルが見えず、ピン止めの目的を果たせないため。

### Front Matter に `pinned:` キーを持つ

不採用。ノート本文の書き換えが発生し、一覧走査時に全ファイルの先頭を読み込む必要があるため（ADR-019 で `created` を使わない理由と同じ）。

### 「Pinned」の区分見出しを追加する

不採用。先頭への配置とピンアイコンの表示で十分に識別でき、常設 UI の増加を避けるため（`AGENTS.md` §4）。
